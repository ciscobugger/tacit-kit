# The Tacit name

Tacit is the Tacit Project's name for its operating system, its apps and its type. The licences in this repository
cover the code (LGPL-3.0-or-later), the fonts (SIL Open Font License 1.1) and the documentation (CC BY 4.0). None of
them gives the right to use the name or the mark.

You may:

- say that an app is made with Tacit.Kit, or that it is made for Tacit;
- name Tacit when you write about it, review it or teach it.

Please don't:

- name an app, a fork, a theme or a service "Tacit ..." or use the mark, in a way that suggests it comes from the
  Tacit Project or is endorsed by it;
- ship a changed font under a name with "Tacit" in it. "Tacit" is a Reserved Font Name under the Open Font License,
  so a modified version of Tacit Sans, Mono, Code or Symbols takes a name of its own.

If you are unsure, ask in the [Tacit Discord](https://discord.gg/Geg72FUhY).
